# thongphan.com v2 — Bộ Tài Liệu Nâng Cấp

> Mục tiêu: biến `thongphan.com` từ site personal brand/blog hiện tại thành một hub chiến lược nối Thông Phan, Brain2, content engine và Conan Maker.

## Cách đọc

Đọc theo thứ tự này để ra quyết định nhanh:

1. `00-strategic-brief.md` — website này tồn tại để làm gì trong hệ sinh thái.
2. `01-current-state-audit.md` — hiện trạng site/repo và gap so với Brain2.
3. `02-prd-thongphan-com-v2.md` — PRD chính cho v2.
4. `03-content-strategy.md` — định hướng nội dung, taxonomy, editorial engine.
5. `04-ux-ia-spec.md` — sitemap, user journey, CTA routing.
6. `05-visual-direction.md` — hướng UI/visual để build nhất quán.
7. `06-technical-plan.md` — kế hoạch kỹ thuật và phase implementation.
8. `07-success-and-stop-criteria.md` — tiêu chí đạt/dừng để quản lý scope.
9. `08-approved-build-prd.md` — hướng đã chốt mới nhất và scope build đang thực thi.

`08-approved-build-prd.md` là tài liệu ưu tiên cao nhất nếu có điểm khác với các bản audit/PRD trước đó.
