# Visual Direction — thongphan.com v2

## 1. Desired Feeling

Visual identity should feel:

- Calm authority.
- Editorial depth.
- Real proof.
- AI-native but not tool-bro.
- Vietnamese, direct, lived-in, not Silicon Valley generic.

Avoid:

- Guru landing page.
- Over-glossy SaaS hero.
- Purple/blue/gold gradient overload.
- Emoji-heavy learning platform vibe.
- Card wall where everything has equal weight.

## 2. Current Visual Assessment

Current UI strengths:

- Dark premium base fits AI/content brand.
- Gold accent has memorability.
- Hero photo gives human proof.
- Blog article direction already has an existing PRD.

Current risks:

- Floating stat cards and glows can make the site feel like a template.
- Emoji icons reduce perceived depth when overused.
- Many sections are cards, flattening hierarchy.
- Dark/purple/gold can become one-note if not balanced with real media and neutral editorial surfaces.

## 3. Visual North Star

Use “field notes from a working AI/content strategist” as the visual metaphor.

This means:

- More editorial layouts.
- More annotated proof.
- More screenshots/real artifacts.
- Less abstract decoration.
- More system diagrams.
- More human photo/proof moments.

## 4. Palette Direction

Keep existing tokens for compatibility:

- Near-black background.
- Gold accent.
- Muted text.

Add balance:

- More neutral grays for reading surfaces.
- Use gold sparingly for decisive highlights.
- Reduce purple glows except where they signal AI system.
- Introduce proof/media blocks with actual screenshots, not only gradients.

## 5. Typography Direction

Use existing heading/body system unless a redesign proves better:

- Heading: Be Vietnam Pro.
- Body/UI: Inter.
- Blog longform may use an editorial serif per existing blog PRD, but test Vietnamese readability.

Rules:

- No negative letter spacing in compact UI.
- No viewport-width font scaling.
- Hero can be large, but dashboard/card headings should be tight.
- Longform line length 65-75 chars.

## 6. Component Direction

### Hero

- Use real Thông photo or proof media.
- Avoid excessive floating cards.
- Put proof stats in a structured strip below or beside hero.
- Hero copy should do the work, visuals support.

### System Map

Build a strong visual for:

```
Kinh nghiệm thật -> Brain2 -> Content -> AI workflow -> Conan
```

This should be a signature section. It can use nodes/lines, but keep it readable and not decorative.

### Proof Blocks

Use:

- Screenshot of viral posts.
- Screenshot of Brain2 graph/vault.
- Screenshot of Chat/AI answer.
- Conan community proof.

Each proof block needs a caption explaining what it proves.

### Cards

Use cards only for repeated choices:

- Choose your path.
- Blog posts.
- Case studies.

Avoid nested cards and floating page sections as cards.

### CTAs

Buttons should be specific:

- `Tự chẩn đoán năng lực AI`
- `Chat với Brain2`
- `Vào Conan Trial`
- `Đọc bài nền tảng`

Avoid generic:

- `Tìm hiểu thêm`
- `Bắt đầu ngay` without context.

## 7. Motion Direction

Use motion to support comprehension:

- Subtle reveal on scroll.
- Progress indicators.
- System map step highlight.

Avoid:

- Constant floating elements.
- Heavy parallax.
- Shimmer everywhere.
- Motion that makes text harder to read.

## 8. Responsive Requirements

Before release, verify:

- Hero text and CTA fit on 375px width.
- No floating stat card overlaps image/text.
- Nav is usable on mobile.
- Blog typography is readable.
- Chat input stays visible and usable.
- Challenge signup form is not squeezed.

## 9. Visual Assets Needed

Minimum:

- High-quality portrait of Thông.
- 2-3 screenshots of viral post performance.
- Brain2 vault screenshot or graph screenshot.
- Conan Maker/community screenshot if allowed.
- Chat/Brain2 answer screenshot.

Optional:

- Simple diagrams exported as HTML/CSS/SVG in code.
- Short video/GIF of Brain2 chat answering a question.

## 10. Design QA Checklist

- Does first viewport show a human/product/proof signal?
- Does the visual hierarchy match the strategic hierarchy?
- Are there too many equal cards?
- Are colors too one-note?
- Does text fit at mobile and desktop?
- Is the CTA obvious without reading the whole page?
- Does the design feel like Thông, not generic AI SaaS?
