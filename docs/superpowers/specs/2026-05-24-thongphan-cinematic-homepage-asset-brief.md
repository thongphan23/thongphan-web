# thongphan.com Cinematic Homepage Asset Brief

Date: 2026-05-24
Status: Draft asset request
Related design: `docs/superpowers/specs/2026-05-24-thongphan-cinematic-homepage-design.md`

## Purpose

This brief lists the exact assets needed to build a high-impact cinematic homepage for `thongphan.com`.

The goal is not to collect random pretty images. Each asset must support one of these jobs:

- Make Thong Phan visually dominant in the first viewport.
- Prove there is a real AI-native system behind the brand.
- Turn proof into trust.
- Help the scroll story transform from chaos to clarity to action.

## Priority 1: Hero Character Assets

These assets determine whether the opening card reveal can feel premium.

### Hero Portrait A: Main Character

Use:

- First viewport reveal.
- Large card unlock.
- Desktop hero focal point.

Requirements:

- Half-body or full-body.
- Face sharp and well lit.
- Neutral or clean background preferred.
- No heavy Facebook/Zalo compression.
- Original iPhone/camera file preferred.
- Minimum recommended size: `2400px` on the long edge.

Pose direction:

- Calm authority.
- Looking at camera or slightly off-camera.
- Crossed arms, standing, seated at desk, or holding laptop are all acceptable.
- Avoid goofy expressions, busy background, low-light blur, or cropped forehead/hands.

### Hero Portrait B: Card Face

Use:

- Before/after card flip.
- Smaller repeated identity moments.

Requirements:

- Clean portrait.
- Strong eye contact.
- Can be tighter crop than Hero Portrait A.

### Cutout Version

Nice to have:

- Transparent-background cutout of Hero Portrait A.

Use:

- Layer Thong in front of graphs, proof fragments, and glow/scan effects.

## Priority 2: Technology/System Assets

These assets make the website feel AI-native instead of decorative.

### Brain2 / Obsidian Graph

Use:

- Brain2 Core scroll scene.
- Node transformation from chaos into system.

Requirements:

- Screenshot can be sanitized.
- No private names, sensitive notes, or personal data visible unless approved.
- Prefer graph view, note network, or vault structure.

### Codex / Open Design / Hermes / Workflow Screens

Use:

- Tech layer in hero or Brain2/Core scenes.

Requirements:

- Capture real tools if possible.
- Hide secrets, API keys, personal data, private client details.
- Good screenshot size: desktop `1440px` or wider.

Suggested screenshots:

- Codex working on a repo.
- Open Design preview.
- Hermes dashboard.
- Brain2 retrieval or search result.
- AI workflow producing a content/proof output.

## Priority 3: Proof Assets

These assets support the Proof Stack scene.

### Viral Post Screenshots

Use:

- Proof cards.
- Flying evidence fragments around hero.

Requirements:

- Show post content enough to feel real.
- Show shares/comments/reactions if possible.
- Crop out irrelevant browser clutter.

Suggested proof:

- A representative post from the `40+ viral` set.
- A post or aggregate screenshot supporting `80k+ shares`.
- Workshop/comment screenshot supporting `600+ comments`.

### Conan Proof

Use:

- Conan Portal scene.
- Demand/trust bridge.

Requirements:

- Avoid exposing private community data.

Suggested proof:

- Conan platform public screen.
- Conan Maker/community proof with names blurred.
- Course/catalog/platform screenshot if it supports current positioning.

These help the page avoid becoming abstract tech.

### Workshop / Teaching / Community Photos

## Priority 5: Video Assets

Video is optional but can make the hero feel much more cinematic.

### Short Hero Clip

Use:

- Background/texture for opening reveal.
- Subtle hover/loop motion.

Requirements:

- 5-15 seconds.
- Stable camera.
- Good lighting.
- Minimal background clutter.
- Vertical or horizontal is acceptable; horizontal is better for hero.

Suggested shots:

- Thong looking up from laptop.
- Thong standing still while light/motion happens around him.
- Thong typing, then looking at camera.
- Close-up of hands using laptop with Brain2/Codex on screen.

## Safety Redaction Checklist

Before any screenshot goes public:

- Hide API keys, tokens, emails, phone numbers, private URLs, and credentials.
- Blur student/customer names unless approved.
- Remove private revenue/internal operations unless intentionally public.
- Avoid showing private Brain2 notes with sensitive personal details.
- Confirm Conan platform/community screenshots are public-safe.

## Minimum Viable Prototype Asset Set

If Anh Thong wants Codex to prototype immediately before collecting all assets:

For final homepage quality:

- One card portrait or cutout.
- At least three proof screenshots.
- One Brain2/system screenshot.
- One Conan/platform or community proof screenshot.
