## Goal

Upgrade `thongphan.com` from a text-and-panel cinematic homepage into a high-impact personal brand experience:

- First impression must feel "wow" and memorable.
- Thong Phan must become the visual focal point, not a small supporting portrait.
- The site must show real AI-native technology: Brain2, Codex/Open Design/Hermes style systems, Conan platform/proof, and live workflow energy.
- The homepage must use 2.5D cinematic scroll where each scroll step transforms the story, not just fades in static cards.
- The experience must still preserve authority, clarity, trust, and conversion to the right next step.

- Thong Phan personal brand exists to build credibility, pull the right people toward Conan, and open future advisory opportunities.
- The current Conan focus is demand for Conan Maker, not rebuilding offer/course strategy.

- Strategic sentence: "Nguoi co chuyen mon khong thua AI. Ho thua nguoi biet bien chuyen mon thanh he thong bang AI."
- Brand state: clarity in chaos. The website should move the reader from AI chaos to clarity and control.

## Current-State Findings

Observed current repo and live site:

- Homepage already has the right narrative sequence: AI chaos, Brain2, asset/cashflow, proof, diagnostic, Conan Trial.
- Current implementation already uses GSAP and sticky cinematic scenes.
- The portrait asset is only `384x472`, currently rendered as a small proof card.

## Recommended Direction

Use a hybrid direction:

1. Game-card reveal for the first 3-5 seconds.
2. Premium 2.5D AI control-room cinematic scroll for the rest of the homepage.

This gives the dopamine of opening a card without turning the brand into a game/NFT/crypto visual language. The scroll direction is specifically 2.5D: layered foreground, midground, and background elements move on different depth planes, appearing/disappearing in sequence as if the viewer is entering a deeper system space.

## Cinematic Scroll Scenes

The homepage should use six scroll scenes.

2.5D structure:

- Background plane: dark/clean system environment, grid, distant graph, light field.
- Midground plane: Brain2 nodes, proof cards, system panels, scan surfaces.
- Foreground plane: Thong cutout/card, signature quote, CTA, selected proof fragments.
- Depth motion: foreground moves slightly faster, background slower; elements can pass behind or in front of Thong to create dimensionality.
- Sequencing: elements should appear, transform, and disappear one layer at a time, not all at once.

### Scene 1: Chaos

Visual:

- Floating AI tabs, prompts, tool names, saved-but-unused prompt fragments, and generic-content warnings.
- Motion should feel like scattered attention.

Transformation:

- The fragments begin to get pulled toward a central axis.

Message:

- AI makes everything faster, but also makes the user's head more chaotic.

### Scene 2: Signal

Visual:

- Chaos stops.
- The signature sentence appears large.

Copy:

- `AI khong cuop viec anh em. Nguoi dung AI gioi hon moi cuop.`

Transformation:

- Fear reframes into clarity.

### Scene 3: Brain2 Core

Visual:

- Fragments become a knowledge graph.
- Prefer real Obsidian/Brain2 screenshots or graph captures when supplied.

Transformation:

- Disconnected experience becomes a system AI can understand.

### Scene 4: Proof Stack

Visual:

- Real screenshots and data cards enter like evidence being assembled.

Proof:

- `14 thang flop`
- `40+ bai viral`
- `80k+ shares`
- `600+ comments`
- `100+ Conan Makers`

Transformation:

- Claims become proof.

### Scene 5: Diagnostic Scan

Visual:

- AI control panel scans the visitor's current stage.

Levels:

- Task AI
- Content leverage
- Brain2 base
- Digital asset
- Conan ready

Transformation:

- Clarity becomes a personalized next step.

### Scene 6: Conan Portal

Visual:

- A platform/portal scene, not a generic CTA card.

Message:

- `21 ngay Brain2 la cua vao. Conan Trial la moi truong thuc hanh.`

Transformation:

- Website becomes an entry point into a real ecosystem.

## Visual System

Use three visual layers.

### Character Layer

Thong is the protagonist. The page must visually say that this is a real person with proof, taste, and operating systems.

Requirements:

- Large portrait in hero.
- Portrait must not be avatar-sized.
- Supporting photos can appear in proof/about-like beats.

### System Layer

The site must show technology as a working system:

- Brain2 graph.
- Terminal/scan language.
- AI memory map.
- Codex/Open Design/Hermes-like operating surfaces if allowed.
- Scroll-linked graph/node transformations.

### Proof Layer

Proof should not sit in static cards only. It should appear as evidence in the cinematic story:

- Viral posts.
- Share/comment screenshots.
- Conan platform/community screenshots.
- Brain2/Codex workflow screenshots.

## Palette And Type

Default palette:

- Deep ink/black for opening and portal moments.
- Clean white/near-white for clarity and readable sections.
- Brand blue and gold as core accents.
- Gold reserved for unlock/reveal/CTA moments.
- Coral/green/sky accents for proof and system status.

Avoid:

- One-note dark purple AI SaaS look.
- Crypto/NFT/game-casino visual language.
- Overusing gold everywhere.

Typography:

- Keep Be Vietnam Pro / Inter foundation.
- Use large, short, hard-hitting headline moments.
- Do not scale font by viewport width.
- Keep letter spacing at 0 except small mono labels where already used.

## Motion System

Use motion to transform meaning.

Allowed:

- Card flip/reveal/scan.
- 2.5D layered parallax with foreground/midground/background depth.
- Scroll scrub.
- Controlled pinning.
- Proof fragments flying into place.
- Graph nodes connecting.
- Scan bars progressing.
- CTA portal reveal.
- Soft depth-of-field / blur only when it clarifies focus.

Avoid:

- Constant floating motion everywhere.
- Motion that makes reading harder.
- Pinning that clips sections or creates layout instability.
- Heavy smooth-scroll dependency unless it measurably improves feel.
- Deep parallax that feels like a gimmick rather than a guided transformation.

Implementation preference:

- Continue using GSAP ScrollTrigger already in repo.
- Use transforms, opacity, clip-path, and filter for smoother animation.
- Add Lenis only if native scroll + GSAP feels insufficient.
- Respect `prefers-reduced-motion`.

## Acceptance Criteria

The homepage upgrade is considered successful only when these criteria are visibly true in the rendered browser:

1. First viewport impact:
   - Thong is visually dominant within the first viewport.
   - The portrait or character card is not avatar-sized or tucked into a small panel.
   - The first 3-5 seconds feel like an unlock/reveal, not a standard hero fade-in.
2. Technology signal:
   - The page clearly communicates Brain2 / AI-native operating system / Conan ecosystem.
   - Technology is represented through system visuals, graph/scan/workflow surfaces, or approved real screenshots.
   - The site does not look like a generic AI SaaS template.
3. Scroll transformation:
   - Each main scroll scene changes the user's mental model:
     - chaos becomes signal,
     - signal becomes Brain2,
     - Brain2 becomes proof,
     - proof becomes diagnosis,
     - diagnosis becomes next action.
   - Scenes must not be only static text cards fading in.
4. Trust:
   - Proof is visible and tied to claims.
   - Proof supports the positioning rather than feeling like vanity numbers.
5. Conversion:
   - Primary CTA is visible after the reveal.
   - CTA hierarchy follows the approved/default route map.
6. Mobile:
   - Mobile still feels cinematic, even if simplified.
   - No text, portrait, cards, proof fragments, or CTAs overlap.
7. Performance and accessibility:
   - Reduced motion is respected.
   - No blank-screen delay before content appears.
   - No scroll-lock, clipping, or layout jump caused by pinning.
